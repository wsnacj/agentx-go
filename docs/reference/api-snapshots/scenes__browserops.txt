package browserops // import "github.com/wsnacj/agentx-go/scenes/browserops"

Package browserops提供可移植的浏览器操作Pack、证据合同与确定性评估机制。

本包不启动浏览器，不访问网络，也不拥有凭据、登录态、审批、文件落盘或站点策略。
