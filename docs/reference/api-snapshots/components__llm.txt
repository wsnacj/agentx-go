package llm // import "github.com/wsnacj/agentx-go/components/llm"

Package llm defines provider-neutral request, response, tool, multimodal, usage,
and streaming contracts shared by AgentX and standalone consumers.

The package is part of the current Developer Preview compatibility surface.
It does not construct an AgentX Runtime, select providers, load credentials,
or perform network requests.

func (l ModelLimits) Normalize() ModelLimits

    known context window. It does not invent an unknown limit.

	CountInput(context.Context, TokenCountRequest) (TokenCount, error)
}

    It must honor ctx and must not mutate the request.
