package publicnews // import "github.com/wsnacj/agentx-go/scenes/publicnews"

Package publicnews provides provider-neutral contracts, deterministic evidence
guards, tool schemas, and Pack definitions for public-news workflows.

It does not perform network access, choose providers, or own credentials and
product-specific source policy.

    BuildLatestNewsBriefCaseInput is a legacy/explicit pack-workflow fallback

    facts.
