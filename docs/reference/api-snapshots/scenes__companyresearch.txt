package companyresearch // import "github.com/wsnacj/agentx-go/scenes/companyresearch"

Package companyresearch provides provider-neutral company-research contracts,
deterministic task planning and evaluation, tool schemas, and Pack definitions.

It does not fetch financial, market, or news evidence and does not produce
investment recommendations.
